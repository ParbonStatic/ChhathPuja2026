# छठ महापर्व | Chhath Mahaparv 2026

A zero-build, single-page tribute to Chhath Puja — Bihar's grandest festival of purity, tapasya and gratitude to the rising and setting sun.

**Live:** https://parbonstatic.github.io/ChhathPuja2026/

## Features
- Zine-style asymmetric layout with Madhubani line-art, animated sunset/river hero and floating leaf-boats
- Significance, 4-day ritual tabs (Nahay-Khay → Usha Arghya), Mahaprasad bento grid, Bihari folk geet
- **Virtual Arghya** studio: vibe presets, editable wish, sunrise glow, petals and confetti
- Blessing card actions: Copy Text, Share, Save PNG (1200×800 canvas), Print

## Run locally
Open `index.html` in any browser. No build step (Google Fonts load from the CDN).

## Open Graph / social preview
`og-image.svg` is the editable source; `og-image.png` (1200×630) is what crawlers read. Re-export the PNG after editing the SVG. Absolute URLs in `index.html` assume `https://parbonstatic.github.io/ChhathPuja2026/` — update them if the URL changes.

## Deploy
Pushing to `main` deploys via `.github/workflows/static.yml` (GitHub Pages → Source: GitHub Actions).
